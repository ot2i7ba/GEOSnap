Crystal ball · estimated search area

The crystal ball estimates where the device is likely to be at a reference time. It uses only the device's own routine: on comparable days (same place, same time of day), where it was the same time later, how far it got, where it went next, how long it stayed and how its silences ended.

It is an estimate from the available records, not evidence of where the device is. Use it only as a starting point for planning a search.
